02 / Method

More capacity, where it matters.

A small region occupies the generator’s full input volume. Boundary anchoring keeps regeneration consistent with the surrounding asset.

01

Select a region

Mark a detail-critical region in the mesh and conditioning image.

02

Enlarge & re-encode

Let the selected submesh fill the generator’s existing spatial grid.

03

Refine with anchoring

Hold boundary latents close to the base; allow stronger changes farther away.

04

Reintegrate

Return the refined region to the original coordinate frame and combine it with the asset.
